# 差异化矩阵（DIFF-MATRIX）· 防换名复用

> 判据（26 号）：与基准癌种并排看，一级名称一致率 > 70% 且二级顺序一致 = 没做场景调研。
> 对比基准：**breast-cancer-workbench 0.12.0**（26 号 §3）；移植样板：**cervical-workbench 0.1.1**（用户指定）。
> 六条差异化种子已在认领 issue #13 签署（场景 → 功能 → 验收），M1 填全量走查表。

## 一、六条 MPM 差异化种子（issue #13）

1. **石棉暴露与职业史线**：暴露时间线/工种/场所/防护 + 职业病诊断材料清单（零法律建议文案）→ 验收：G1 + 词表测试。
2. **胸水事件轨道**：胸穿/引流/胸膜固定术独立轨道 + mMRC 呼吸困难分级卡（不进趋势）→ 验收：独立轨道读模型断言。
3. **病理三型与分子线**：上皮样/肉瘤样/双相 + BAP1/SMARCB1/MTAP 三态（未检测 ≠ 阴性）→ 验收：三态契约冻结。
4. **免疫治疗反应语境**：双免周期档案 + 反应模式只抄原文（iRECIST 假性进展语境，不判读）→ 验收：无判读列。
5. **胸膜影像测量专线**：modified RECIST 胸膜厚度测量并列（测量值/原文/当时 mMRC）→ 验收：并列无判读。
6. **就诊弯路时间线**：初诊印象/检查/转诊记录（误诊延迟数月是高频叙述），照护者代记友好 → 验收：独立轨道。

## 二、功能线对照（M1 填全量）

| 功能线（26 号 L1–L10） | breast 基准做法 | MPM 做法（草案） | 刻意不同 |
| --- | --- | --- | --- |
| L2 疾病本体 | 病理·分子档案（ER/PR/HER2） | **「我的瘤」= 病理三型 + 分子三态 + 就诊弯路**两条子线 | 弯路进疾病本体（确诊即弯路终点） |
| L3 治疗与决策 | 术后上肢、内分泌决策 | 化疗/双免周期 + **胸水管理**（胸穿/固定术独立） | 胸水是治疗线的一等公民 |
| L4 指标分析 | CTCAE 分级卡 | 血象 + **mMRC 呼吸困难卡**（分类）+ 胸水生化 | mMRC 替代 KPS 成为功能分类主卡 |
| L5 安全与症状 | 淋巴水肿 | 气促/胸痛轨道 + 感染 | 呼吸症状为主线 |
| L6 营养与体重 | 体重曲线 | 体重 + 胸水期进食语境 | 同构 |
| L7 心理与家庭 | 遗传咨询（BRCA） | **照护者线 + 职业赔偿材料跟进 + ACP** | 家属线含材料经办场景 |
| L8 复诊随访 | 影像间隔 | CT 并列（modified RECIST）+ 材料清单节奏 | 材料跟进与复查同轨 |
| L10 试验线索 | 登记库 | 同（四通道，MPM 口径） | 双免/石棉相关研究词加权 |

## 三、结构性判据自查（M2 复核）

## 二、一级 10 线 vs cervical（12 级/38 页签实测）vs breast 基准（全量，family-landscape §6）

10 条线：看板（双主体，特色状态卡=胸水最近事件+mMRC 现分级）/ 我的瘤与弯路（不做分期库，改三型+三态+弯路）/ **石棉与材料（家族独有整线，零法律建议红线）** / 治疗档案（化疗+双免两主径+反应模式原文列）/ **胸水与呼吸（家族独有整线）** / 血象与指标（mMRC 卡替代 KPS/SCC-Ag 成功能主卡）/ **随访影像（升一级，mRECIST 三列并列禁判读）** / 病情一图秀（胸水引流量+胸膜厚度+体重，mMRC 分类节点）/ 照护与生活（L6+L7 合并，含材料经办）/ 复诊与资料（L8+L9+L10 合并 5 子页，材料跟进同轨）。
逐线对照表与二级 30 页签清单见 `research-notes/family-landscape.md` §6.1/§6.2。

## 三、结构性判据自查（实测 2026-10-24）

- 一级 10 / 二级 30（阈值 8–10 / 24–30 ✅）；**与 cervical 一级完全同名 2/10 = 20% ≤70% ✅**（宽松口径 ~40% 仍过）。
- 6 差异化种子全部落线；S01–S13 全覆盖；每条线挂患者原话（改写口径已声明）。
- **3 个 G1 决策点（显式不沉默）**：① 疾病与弯路 vs 弯路独立成线（草案：并入疾病本体）；② 照护与生活 L6+L7 合并 vs 分列（草案：合并，同 HCC 先例）；③ 一图秀独立页 vs 挂指标线子页（草案：独立页，GBM 教训 P0-② 同款）。
