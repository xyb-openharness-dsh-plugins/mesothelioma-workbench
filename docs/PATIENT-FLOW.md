# 患者流程（PATIENT-FLOW）· 三流骨架（M1 调研后填实）

> 页面树由三条流反推，不从医生流程照搬。每条流：最难受时刻 → 打开哪页 → 得到什么产物。

## 流一：确诊弯路与确诊（疑似→活检→病理三型）→ 差异种子 #6/#3

- 时刻：胸水反复几个月，先后被当过结核性胸膜炎、怀疑肺癌转移，换了两个医院才做上胸膜活检；病理报告"上皮样型""BAP1（−）"读不懂；医生问"你年轻时做什么工作"，才第一次把石棉史串起来。
- 打开：就诊弯路时间线 → 我的瘤 · 病理与分子（三态）→ 职业暴露档案（把散落记忆整理成时间线）→ 职业病材料清单。
- 产物：弯路时间线 + 分子档案摘要 + 材料清单第一版。
- 双主体注意：弯路由照护者代记友好（witnessed/author 标签）。

## 流二：治疗与日常（化疗或双免 + 胸水反复）→ #2/#4

- 时刻：培美曲塞+顺铂第 3 周期或双免第 5 周；又得去抽胸水，这次引出了 800ml；爬两层楼就喘（mMRC 2 级）；血象低。
- 打开：治疗档案（周期/反应模式原文）→ 胸水事件轨道（本次穿刺/引流量/缓解）→ 指标与用药（血象 CTCAE）→ 呼吸困难 mMRC 卡。
- 产物：当日记录 + 症状与治疗并排时间线 + 问题清单积累。
- 双主体注意：引流由照护者代记（引流量/时间）。

## 流三：随访与长程（CT 复查 + 照护决策 + 材料跟进）→ #5/#1

- 时刻：CT 报告"胸膜增厚较前进展"——是进展还是免疫治疗反应？职业病诊断材料还差三份；家属开始查临床试验。
- 打开：随访影像 · CT 并列（modified RECIST 测量/原文/当时 mMRC）→ 问题清单生成 → 职业病材料清单跟进 → 试验线索（MPM 口径）→ 照护与家事（决策/ACP）。
- 产物：复诊摘要（private 过滤）+ 材料清单状态 + 收藏线索。

## 反推原则

两条以上流经过 → 一级；单流 → 二级；无流 → 不做。M1 后落 10 级左右一级 / 27±3 二级枚举，与 DIFF-MATRIX 逐线对照（一级重名率 ≤70% 判据）。
