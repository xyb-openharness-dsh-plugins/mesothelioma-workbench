# 项目规格 v0.1（SPEC）· 恶性胸膜间皮瘤患者工作台「小胸宝 PleuraPal」

状态：**草案，待 G1 签认**。产品：MPM 患者与照护者双主体工作台 · 占位品牌「小胸宝 PleuraPal」· `mesothelioma-workbench`。

## 0. 需求审计摘要

- **核心需求**：MPM 患者与照护者在本机整理石棉暴露史与职业病材料、就诊弯路、病理三型与分子三态、胸水事件与 mMRC、化疗/双免治疗、CT 随访（modified RECIST 语境），准备复诊与试验线索；全病程覆盖。
- **隐含需求**：本机优先；visibility 分级 + **工友证言第三方信息专项授权**；无判读列；材料清单零法律建议；双源标签；MinerU 候选核对闭环。
- **G1 待拍板**：① 三个结构决策点（DIFF-MATRIX §三）② 品牌占位名 ③ 二期候选 S14–S17。

## 1. 依据

调研：`research-notes/{medical-constraints,user-research,family-landscape}.md`（30 源 + 47KB 用户研究 + cervical/breast 实测）。追踪链 E→N→S（SCENARIOS S01–S17）→F（§4）→A（§7）。医生工作流不直接成为功能树；证据分层（0 访谈如实标注）。

## 2. 用户与最小闭环

双主体并重（用户默认，可回退）。最难受时刻：弯路与确诊（流一）、胸水反复与治疗期（流二）、CT"进展"恐慌与材料跟进（流三）——见 PATIENT-FLOW。
**最小闭环**：登记一份 CT 报告 → 随访影像并列（测量/原文/当时 mMRC）→ 问题清单生成 → 复诊导出（private 过滤）。失败恢复：导入失败原件保留、候选拒入事实层。

## 4. 功能范围（10 线 30 页签，G1 签认对象）

全量见 DIFF-MATRIX §二与 family-landscape §6.1/§6.2。功能 ID：F-DASH / F-TUMOR（含弯路）/ F-ASBESTOS（石棉与材料）/ F-TX（治疗档案）/ F-PEX（胸水与呼吸）/ F-LAB（血象与指标）/ F-CT（随访影像）/ F-CHART（病情一图秀）/ F-CARE（照护与生活，**支持资源并入 ACP 与决策页下半区，二期可升独立页签**——评审 P1-3 方案 B）/ F-FU（复诊与资料 5 子页）/ F-SET（设置弹窗三页签）。

## 5. 数据与 API（G3 冻结对象）

`schema/draft/0001_mpm_specific.sql`（10 专属表，判读列断言 PASS）+ 家族通用（cervical 35 表结构平移，G3 合并冻结）。四契约 + apiBase 定稿契约。API 前缀 `mesothelioma`；MinerU 设置接口按 18 号 §5.2。

## 6. 四核心模块

① 病情整理（我的瘤与弯路 + 随访影像）② 指标检测与分级（血象 + mMRC 卡）③ 独立病情一图秀（胸水引流量/胸膜厚度 + 体重，mMRC 只节点不连线）④ 营养/心理/照护（含材料经办）。

## 7. 验收（✅ 实测 / 🔧 骨架 / ⏳ 未实现，严禁虚报）

G1 四文档签认 → G2 原型四必查件 + **HVT X1–X4**（28 号）→ G3 冻结 sha256 → V1 check 全绿 → V2/V3 装机业务验证。DESIGN-REVIEW 独立评审留痕。

## 8. 交付与发布 / 确认关口 / HTML 先行 / 数据演进
