### 定义

恶性胸膜间皮瘤是起源于胸膜间皮细胞的恶性肿瘤。卫健委 2025 版指南记载，接触石棉纤维是最主要的致病因素，约 80% 的病例与之相关；从石棉暴露到发病的潜伏期约 20～50 年，发病高峰在接触后 45 年。中华医学会 2021 版写暴露后 20～40 年发病、平均约 35～40 年，两处表述不一致，本台并排列出、不作裁断。

病理分三型：上皮样型、肉瘤样型、双相（混合）型，双相型要求两种成分均大于 10%。分期参照 AJCC 第 8 版（2017），其来源为 IMIG 2016 提案。确诊常经胸腔积液细胞学或胸膜活检，免疫组化按「至少 2 个间皮瘤标志物 + 2 个肺腺癌标志物」组合排除肺腺癌。本台只整理胸膜型，腹膜型、心包型、睾丸鞘膜型不套用这一套模板：AJCC 第 8 版为胸膜与腹膜各设一套 TNM，两套不互相套用，也不换算。

### 目前治疗全景概要

只列指南与说明书里出现过的手段类别，按病期与线序分组，不排序、不比优劣。获批适应症的人群限定词逐字保留，是否在你身上成立由医生判断。

**可切除评估下的局部治疗**：手术——中华 2021 版写 Ⅰ～ⅢA 期存在手术切除的可能性、ⅢB～Ⅳ 期不推荐手术，NCCN 患者版只对 1 期上皮样提供「手术 + 全身治疗」选项，术式为胸膜剥脱术（P/D）或胸膜外全肺切除（EPP）；MARS 与 MARS2 研究均未显示生存获益，卫健委 2025 版称手术作用「更加具有争议」。放疗——本项目资料未整理间皮瘤的放疗适应证与剂量，本段不展开。

**一线全身治疗**：培美曲塞联合顺铂（不能耐受顺铂者可用卡铂方案），需配合叶酸、维生素 B12 与地塞米松预处理；培美曲塞+顺铂+贝伐珠单抗——卫健委 2025 版写入方案，同时写明「贝伐珠单抗尚未被 NMPA 批准用于不可手术 MPM 患者」；双免疫——纳武利尤单抗联合伊匹木单抗，NMPA 批准用于「不可手术切除的、初治的非上皮样恶性胸膜间皮瘤成人患者」，获批人群限定「非上皮样」，与 CheckMate-743 的全人群证据不是同一范围；免疫加化疗——帕博利珠单抗联合培美曲塞与铂类，FDA 于 2024-09-17 批准，中国 NMPA 状态未核实。

**胸水与胸膜局部处理**：留置胸腔引流管（持续引流反复积液）；滑石粉胸膜固定术（让两层胸膜粘连闭合胸腔）；胸腔内化疗——本次检索未见 2021/2025 中文规范与 NCCN 患者版将其列为标准治疗，如实际做过，按「实际接受的操作」记录。

**复发与后线**：培美曲塞或铂类再挑战；纳武利尤单抗单药（CONFIRM）；吉西他滨 ± 雷莫芦单抗（RAMES）、长春瑞滨；临床试验（NCCN 患者版把临床试验与标准治疗并列，研究用药由申办方承担、安慰剂「almost never used alone」）。

> 以上是文献与指南里列出的手段，按病期与线序排列，不代表任何一项适合你。选哪一个，这一句需要问你的医生。

## 开发与本地验收

需要 Node.js 22+、Git、包管理器和可用 DSH Desktop；采用 SQLite 时另核验 node:sqlite 版本条件。宿主 peers 的范围仅是模板基线，请与目标 Desktop 实际依赖核对。

```bash
npm install
npm run check
npm run pack:check
npm pack
```

`npm run check` 只保证"能装"（语法 + 装包合同），第一天就该是绿的。`npm run audit` 管"还是不是家族里的一员"：版本三处一致、`lib/layout.js` 面板参数单一来源、检查链完整、文档与密钥卫生，**只看代码与文件，不看文档自述**。新项目刚生成时 audit 必然有 fail，那是待办清单；交付/发布前必须清零，存在 fail 不得发布（`npm run release:check` 一次跑完两者）。

`npm install` 可能按 npm 策略解析 peer；勿为消警告重复打包宿主 runtime。客户端本身是单文件；引入 TS/组件库后需添加构建步骤并保留单文件导出。

本地安装入口以当前 Desktop/CLI 帮助为准。安装后按 [docs/06-VALIDATION-AND-RELEASE.md](docs/06-VALIDATION-AND-RELEASE.md) 与官方自测完成真实 UI 验收，并填写 [docs/ACCEPTANCE.md](docs/ACCEPTANCE.md)。静态检查不代表已加载。

Logo 来源与使用限制见 assets/README.md。许可证、作者、仓库/发布策略由本项目维护者确认后填写；模板默认为 private/UNLICENSED。
